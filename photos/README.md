# photos

청첩장 하단 사진 스트립에 들어갈 사진을 이 폴더에 넣습니다.

1. 이 폴더에 이미지를 넣는다. (`.jpg` `.jpeg` `.png` `.webp` `.gif` `.avif`)
2. 저장소 루트에서 `./update-photos.sh` 를 실행한다.
3. `photos/photos.js` 가 다시 만들어지고, 그 순서대로 청첩장에 노출된다.

노출 순서는 파일 이름 순입니다. 순서를 정하려면 `01-...`, `02-...` 처럼 숫자를 앞에 붙입니다.

사진이 한 장도 없으면 섹션 전체가 숨겨집니다.

## 권장 사양

- 가로 세로 비율 3:4 (세로 사진). 다른 비율도 들어가지만 썸네일에서 가운데 기준으로 잘립니다.
- 긴 변 1600px 내외, 장당 500KB 이하. 모바일에서 열기 때문에 원본을 그대로 올리지 않습니다.
